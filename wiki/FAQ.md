# FAQ

## Where can I download the game?
Check the GitHub Releases page for Windows builds.

## Can I remap controls?
Yes. Use Settings to change keybinds.

## Where is the save file?
The save file is stored at user://savefile.json.

## How do I reset progress?
Delete user://savefile.json and restart the game.

## How do I run the project locally?
Open the project in Godot 4.x and press Play.

## How do I export a build?
Use Project -> Export in Godot and select the Windows preset.

## Why does the shop not show a weapon?
Weapons the player already owns are filtered out of the shop pool.
